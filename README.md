# 🗺️ Holographic AI Architecture Decision Map

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)

An open-source knowledge base and practical guide designed specifically for **non-technical founders, Product Managers, and cross-disciplinary professionals**. 
This project transforms the complexity of modern software architecture, AI-Driven Workflows, and strict medical-grade compliance into an interactive visual map and plain-language manuals.

👉 **[繁體中文版](README_zh-TW.md)**

## ✨ Core Features

*   🗺️ **Interactive Holographic Map (`全息架構地圖.html`)**: Requires zero server setup. Double-click to open in any browser. It visualizes the entire from-scratch development workflow, allowing you to read corresponding manuals by clicking on nodes.
*   🏗️ **Tech Stack Selection Guide**: Offers "Golden Combinations" (e.g., `React + Supabase`) tailored for different product stages (MVP, Enterprise, AI-specialized) to cure decision paralysis.
*   🏥 **Medical-Grade Compliance**: A defense guide built for Biotech and Healthcare AI. Covers FDA/HIPAA-level Zero-Data Retention APIs, De-identification Gateways, and immutable database Audit Logs.
*   🛡️ **Commercial Blind Spots**: In-depth analysis of the top three fatal mistakes made by non-technical managers: AI Context Rot, `.env` Key Leaks, and missing DB Primary/Foreign Key relations.
*   🚀 **Zero-to-One Sandbox**: Includes a "10-Minute Countdown Timer" practical exercise. It guides beginners to experience Prompt-Driven Development (PDD) using AI Agents (like Antigravity or Cursor) without writing a single line of syntax manually.

## 📂 Project Structure

This project consists of a visual HTML engine and multiple Markdown (`.md`) manuals. GitHub natively renders Markdown beautifully, so you can read directly on the platform or download the repository to navigate via the HTML map.

```text
├── 全息架構地圖.html                     # The core visual command center (Double-click to run)
├── 實務擴充：沙盒專案實戰演練...md        # Prompt-Driven Development Sandbox Tutorial
├── 實務擴充：醫療級AI專案最高合規指南...md # Medical/Biotech Security & Compliance Guide
├── 實務擴充：商業級專案的三大致命盲點...md # Architecture & Security Pitfalls
├── 第零階：AI開發裝備與實戰起手式...md    # Phase 0: Environment Setup & Cursor Guide
├── 階段一～四_教學手冊.md                 # SDLC Standard Operating Procedures (Phase 1-4)
└── 技術決策地圖：前後端、資料庫選型.md    # Core Technology Framework Analysis
```

## 🚀 How to Start?

### Option A: Use the Visual Map (Recommended)
1. `Clone` or download the ZIP of this repository to your local machine.
2. Locate `全息架構地圖.html` and double-click to open it in your browser (Chrome, Edge, Safari, etc.).
3. Click on the nodes or top navigation buttons to begin your learning journey.

### Option B: Read directly on GitHub
1. Browse and click on the `.md` files in this repository.
2. We recommend starting with **`第零階：AI開發裝備與實戰起手式_教學手冊.md`** (Phase 0).

## 💡 Learning Advice

If you only have minimal experience (like a bit of Google Apps Script) or are completely new to coding, we highly recommend starting with the **"🔥 Sandbox Practical Exercise"**. This will help you overcome the psychological barrier of "writing code" and build the muscle memory required for AI-assisted development.
