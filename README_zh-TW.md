# 🗺️ 全息 AI 架構決策地圖 (Holographic AI Architecture Decision Map)

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)

專為「非技術背景的專案負責人、PM 與創業家」打造的開源知識庫與實戰指南。
本專案將複雜的現代軟體架構、AI 驅動開發流程 (AI-Driven Workflow) 以及最高級別的醫療法規合規性，轉化為視覺化的互動地圖與白話文手冊。

👉 **[English Version](README.md)**

## ✨ 核心特色功能

*   🗺️ **互動式全息地圖 (`全息架構地圖.html`)**：完全不需安裝伺服器，點擊兩下即可在瀏覽器開啟。將從零到一的開發流程與知識點進行節點視覺化，點擊節點即可在右側閱讀對應手冊。
*   🏗️ **技術棧選型指南**：針對不同階段的產品（MVP 試水溫、高階商用、AI 特化），提供如 `React + Supabase` 等黃金組合建議，解決選擇困難症。
*   🏥 **醫療級合規防禦**：專為生技與醫療 AI 打造的防護指南。涵蓋 FDA/HIPAA 級別的 Zero-Data Retention (零資料保留 API)、去識別化閘道與資料庫稽核軌跡 (Audit Logs)。
*   🛡️ **商業盲點掃雷**：深度解析非技術主管最常踩坑的三大致命傷：AI 上下文失憶、`.env` 金鑰外洩、以及資料庫 Primary/Foreign Key 關聯性設計。
*   🚀 **零基礎沙盒實戰**：內建「十分鐘倒數計時器」實戰教案，帶領新手不寫一行語法，透過 AI Agent (如 Antigravity, Cursor) 體驗 Prompt-Driven Development (指令式開發)。

## 📂 專案結構

本專案主要由一個視覺化 HTML 引擎與多份 Markdown (`.md`) 教學手冊組成。GitHub 天生支援 Markdown 渲染，您可以直接在平台上閱讀，或下載後使用 HTML 地圖進行導覽。

```text
├── 全息架構地圖.html                     # 核心視覺化指揮中心 (雙擊即可開啟)
├── 實務擴充：沙盒專案實戰演練...md        # 指令式開發教學教案
├── 實務擴充：醫療級AI專案最高合規指南...md # 醫療/生技領域專用防禦指南
├── 實務擴充：商業級專案的三大致命盲點...md # 資安與架構避坑指南
├── 第零階：AI開發裝備與實戰起手式...md    # 新手環境設定與 Cursor 教學
├── 階段一～四_教學手冊.md                 # 軟體生命週期標準流程 (SDLC)
└── 技術決策地圖：前後端、資料庫選型.md    # 核心技術框架解析
```

## 🚀 如何開始？

### 選項 A：使用視覺化地圖 (推薦)
1. 將此專案 `Clone` 或下載 ZIP 解壓縮到您的電腦。
2. 找到 `全息架構地圖.html`，點擊兩下使用瀏覽器（Chrome, Edge, Safari 等）開啟。
3. 點擊畫面上的節點，或是上方導覽列按鈕，開始您的學習之旅。

### 選項 B：直接在 GitHub 閱讀
1. 直接點擊本倉庫中的 `.md` 檔案。
2. 從 **`第零階：AI開發裝備與實戰起手式_教學手冊.md`** 開始閱讀。

## 💡 學習建議

如果您是只懂一點點 Google Apps Script (GAS) 或是完全零基礎的新手，強烈建議您從**「🔥 沙盒專案實戰」**開始。這能幫助您快速跨越「不敢寫程式」的心理障礙，並建立與 AI 協同開發的肌肉記憶。
